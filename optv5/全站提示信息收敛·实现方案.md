## 2. 文案 SSOT（必须先建）

### 2.1 新建文件

**路径**：`frontend/src/utils/copywriting.ts`

**内容要求**（Agent 按下列导出，勿改语义）：

```typescript
/** 全站用户可见固定文案（HI-1：免责声明只引用此处）。 */
export const DATA_SCOPE_DISCLAIMER =
  '当前展示的是规整后可用的工作数据，不是领导签字发布的正式报表。'
/** 短版：用于导出 toast 等单行场景。 */
export const DATA_SCOPE_DISCLAIMER_SHORT = '内部参考，非正式报表。'
/** 问数页结果区：不再重复长 disclaimer，只用此短句（可选）。 */
export const ASK_RESULT_SCOPE = '基于当前可用数据'
```

### 2.2 引用规则（硬约束）

| 文案主题 | 允许出现位置 | 禁止出现位置 |
|---|---|---|
| `DATA_SCOPE_DISCLAIMER` | **仅** HomeView.vue 顶栏 `el-alert` 的 `:description`（待办=0 且 `clean_rows>0` 时）或固定挂载 | 其他所有页面 |
| `DATA_SCOPE_DISCLAIMER_SHORT` | BrowseView 导出 ElMessage、可选 CSV 文件名后缀 | alert 标题、表格列 |
| `ASK_RESULT_SCOPE` | AskView 结果区 **最多 1 处**（见 §5.3） | 顶栏 alert |

以下字符串在业务可见路径中 **整句删除**（不是替换）：

- 不等于正式发布
- 非正式发布
- 可用候选
- 不等于库存事实
- 上传成功不等于解析完成（接入页顶栏整段删除）

## 8. 中英文约束（本方案 SSOT）

### 8.1 分层原则

| 受众 | 页面 | 标准 |
|---|---|---|
| 业务用户 | Home / Ask / Intake / Browse / Data（含 ReportsCatalog） | **零裸英文**：状态词、表名、SQL 列名须汉化或隐藏 |
| 运维 | System 子 Tab | label 中文；存储值可英文 |
| 治理 / 指标 | Govern / Metrics / Stage | 中文为主；`:value` 可英文 |

### 8.2 硬约束

- 用户可见 label / description / button / toast：**中文**
- `el-option` 的 `:value` 可英文（inventory 等），**label 必须中文**
- 不得在 UI 文案或单元格裸露 `STAGED`、`IN`/`OUT` 等（除非 ops 专用折叠且本方案已要求删除）

### 8.3 统一术语表（改文案只改本节）

| 英文 / 内部 | 中文 | 备注 |
|---|---|---|
| gate / ready / blocked | 门禁 / 就绪 / 阻塞 | |
| L1 / L2 / L3 | 规则直出 / 规则+校验 / 模型兜底 | |
| Stage（模型） | 模型阶段 | 接入「规整」不说 Staging |
| OpsToken | 操作令牌 | |
| LLM | 大模型 | |
| Text2SQL / AST | 自动生成查询 / 语法校验 | |
| 非正式发布 / 可用候选 | **删除**（仅 HomeView 保留 §2 disclaimer） | |
| IN / OUT（flow_type） | 入库 / 出库 | `valueZh()` |
| category / year / limit / min_qty | 物资种类 / 年份 / 条数上限 / 最小数量 | ReportsCatalog `PARAM_LABEL_ZH` |

### 8.4 字段汉化工具（前端 SSOT）

| 工具 | 路径 | 用途 |
|---|---|---|
