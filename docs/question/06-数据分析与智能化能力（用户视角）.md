## 一、数据分析能力（用户可直接用）

| 入口 | 能力 | 怎么用 |
|---|---|---|
| **总览**（HomeView） | 9 张**业务组**指标卡（`metric_group=business`）；库存总量/金额、定额利用率、超定额、呆滞料、需求总量、资产台数、入库/出库合计；按类别/库位/单位 Top | 打开即看；金额/呆滞无源数据时显示「暂无数据」（U-3） |
| **问数**（AskView） | 指标模板秒回 + LLM Text2SQL + ECharts 图表 | 直接问「库存总额多少」「低于最低库存有多少」 |
| **数据中心**（DataView） | 明细浏览（PagedTable）、汇总报表目录（种子报表 run **免 Ops Token**，RP-5）、趋势 Tab；`/export/table?mode=business` 中文表头 | 查表、跑报表、导出；旧 `/browse`、`/reports` 已 redirect |
| **指标字典**（MetricsView，系统页内） | 16+ 项 active；按 business/quality/ops 分组（U-1） | 看口径、看状态，自然语言命中即答 |
| **台账模板导出** | `GET /export/ledger/{sheet}` 四 sheet 固定列序（T8） | 还原维护材料/备品备件/应急备汛/公用工器具台账样式 |
| **标准表导出** | `/export/table` 按表 `TABLE_FIELD_ZH` 汉化；`flow_type` 值域已汉化（U-6） | 底层数据随时取 |

**安全护栏**：问答与报表 SQL 均过 AST 只读校验。

## 二、智能化能力（系统自动做，核心价值）

| 智能模块 | 机制 | 效果 |
|---|---|---|
| **接入即治理** | 305B 配置 → LLM 流水解析 → 表头映射 → 物资对齐 → 数量勾稽 | mapping 46/46；对齐 gap 可清单化 |
| **规则自学习** | rule_learn 提案 → 人工确认 → 回写别名库 | 越用越准 |
| **质量门禁** | FLOW_* 质量门 + value_rule + staging_blocked | 不合格数据进不来也答不出 |
| **多模型互验** | big/fast + Stage1 评测全绿 | Stage2 gate 尚未 claim（见 [02](02-模型问题反馈.md)） |

## 三、典型用户工作流

1. **日常监控**：总览快照看总量/定额/呆滞 → 发现异常
2. **查数**：问数页问指标（秒回）或问明细（SQL + 图表）；数据中心浏览/跑报表
3. **定期汇报**：数据中心报表目录下载趋势/Top/类别汇总；或台账 `/export/ledger/{sheet}`
4. **治理维护**：治理中心确认映射、规则学习、勾稽差异、流水解析（ops 在系统页）
