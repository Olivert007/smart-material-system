## 目标架构（已实现）

侧栏 **6 顶级**（业务用户默认见 5 项，`ops` 角色见「系统」）：

| 侧栏 | 路由 | 壳页 / 组件 |
|---|---|---|
| 总览 | `/` | `HomeView`（精简） |
| 问数 | `/ask` | `AskView` |
| 数据中心 | `/data` | `DataView` → detail / report / trend |
| 接入 | `/intake` | `IntakeView` |
| 治理 | `/govern` | `GovernHub` → work / assets / metrics(只读) |
| 系统 | `/system` | `SystemView` → ops/models/lineage/audit/metrics(编辑)/settings |

**重定向**：`/browse`→`/data?tab=detail` · `/reports`→`tab=report` · `/learning`→`/govern?tab=assets` · `/metrics`→`/govern?tab=metrics` · 平台五页→`/system?tab=*`

**角色**：`App.vue` 按 `localStorage.ops_role === 'ops'` 显示「系统」菜单。

## 页面职责清单（SSOT · 新增页门禁）

| 路由 | 唯一职责 | 禁止承担 |
|---|---|---|
| `/` | 待办 + KPI 快照 + 下钻链 | 全站导航、模型详情、整表导出 |
| `/ask` | 自然语言 ad-hoc 查数 | 固定报表、治理写操作 |
| `/data` | 明细浏览、汇总报表、趋势、导出 | 治理确认、SQL 编辑 |

| `/system` | 运维、模型、血缘、审计、指标编辑、设置 | 业务 KPI 展示 |
