# 页面背景配色对齐（参考三峡集团子站）

> 版本：v0.1（2026-08-10）· 状态：待评审
> 视角：**视觉设计对齐**——以参考页的颜色分割为准，评估并调整系统页面背景/导航/主题色
> 参考页：[三峡集团子站-组织概况](https://www.ctg.com.cn/sxjt/ddjs91/zzgk/index.html)
> 范围：`frontend/src/App.vue`、`frontend/src/style.css`、`frontend/src/main.ts`（Element Plus 主题）

---

## 0. 结论摘要

参考页颜色分割为典型的**国央企蓝色系**：白色页面底 + 淡青蓝导航条（#E5EEEF）+ 深蓝基调（#013875）+ 高亮蓝（#0D6FB8），无红色元素。当前系统为 **Element Plus 灰白 admin 风**：浅灰底（#f5f7fa）+ 深蓝灰侧边栏（#1f2a37）+ 默认蓝主题（#409EFF）。

对齐后页面背景由"浅灰"变为"白底 + 深蓝侧边栏 + 蓝色强调"，视觉上更接近参考页的国企蓝风格。改动仅限 CSS 变量与 Element Plus 主题覆盖，不涉及任何页面结构与后端能力。

## 4. 落地方式（最小改动）

1. **Element Plus 主题覆盖**（`main.ts` 引入，或 `style.css` 覆盖 CSS 变量）：
   - `--el-color-primary: #0D6FB8`（含 hover/active 衍生色）
2. **[App.vue](file:///workspace/2026-07/smart-material-system/frontend/src/App.vue)**：
   - `.layout` 背景 `#f5f7fa → #FFFFFF`
   - `.aside` 背景 `#1f2a37 → #013875`
   - `.aside :deep(.el-menu-item.is-active)` 背景 `#0D6FB8`、白字
   - `.header` 底边 `#ebeef5 → #E7E7E7`
3. **[style.css](file:///workspace/2026-07/smart-material-system/frontend/src/style.css)**：主文字色 `#1f2a37 → #3A3A3A`（可选）

仅 3 个文件、纯颜色值改动；页面结构、组件、后端零改动，回归风险极低。

## 5. 决策点

| ID | 决策点 | 候选 |
|---|---|---|
| ED-1 | 页面主底色 | 纯白 `#FFFFFF`（推荐，完全对齐参考页）/ 保留浅灰 `#f5f7fa` 仅改侧边栏与主题色 |
| ED-2 | 主题色替换范围 | 全局替换 `--el-color-primary`（推荐，风格统一）/ 仅侧边栏与页面背景 |
| ED-3 | 正文色是否跟随 | 改 `#3A3A3A`（对齐参考页）/ 保留 `#1f2a37`（改动更小） |

## 6. 验收总标准

1. 页面背景为白底，侧边栏为深蓝 `#013875`，激活/悬停为高亮蓝 `#0D6FB8` 白字；
2. 按钮/链接/tag 等交互色为 `#0D6FB8` 系（Element Plus 主色已覆盖）；
3. 现有页面结构、路由、组件、后端能力不受影响；
4. 深浅对比满足可读性（白字在 `#013875`/`#0D6FB8` 上）。
