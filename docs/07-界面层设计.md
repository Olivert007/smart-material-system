# 模块 07 · 界面层（Web UI）

> 版本：Phase 2.4（2026-08-10）  
> 定位：**独立前端**（前后端分离），只消费同源 **`/api/v1`**，为治理方案提供展示与操作界面。  
> 部署拓扑、Nginx/Vite、SSE、OpenAPI 生成见 **[11-前后端分离与容器化](11-前后端分离与容器化.md)**（SSOT）。  
> 决策：按用户旅程分组 **6 顶级入口 + 2 子路由**（`/stage/:id`、旧路由 redirect）；Compose 为目标、单容器为 PoC。  
> 实施路线图：`smart-material-system/roadmap/MASTER-optimization.md`（Wave 0–4 + IA-W1–W5 已落地）。

## 1. 架构与部署

| 环境 | 浏览器入口 | API |
|---|---|---|
| 开发 F1 | `127.0.0.1:5173`（Vite 容器） | 代理 → `api:8010` |
| MVP F2 | `127.0.0.1:8010`（FastAPI 托管 dist） | 同源 `/api/v1` |
| 正式 F3 | `127.0.0.1:8080`（Nginx 容器，**唯一映射**） | Nginx → `api:8010` |
| PoC | 单容器临时多端口 | 过渡，非终态 |

```
浏览器 → 前端入口（Vite 或 Nginx）
           │ 相对 /api/v1 、 /events
           ▼
         api:8010 ──► meta/SQLite、只读 DuckDB、内部 vLLM
```

硬约束（C13）：

- `const API_BASE = "/api/v1"`；**禁止**业务代码写死 `localhost:8010` / vLLM 端口。  
- 前端**不**直连 DuckDB、SQLite、vLLM。  
- 只做展示与操作提交，**不算指标、不裁定映射/发布资格**。  
- 写操作：鉴权 + `version`/`Idempotency-Key`（05/11）；无权限则按钮禁用。  
- **不提供**常规一键 legacy ingest；须 Deprecated + 二次确认。

## 2. 技术栈

| 项 | 选型 | 理由 |
|---|---|---|
| 框架 | Vue 3 + Vite | 轻量、容器化开发 |
| UI | Element Plus（按需） | 表格/表单/进度 |
| 图表 | ECharts（按需） | 本地打包 |
| HTTP | axios + **生成客户端**（OpenAPI） | 契约一致（C14） |
| 服务端状态 | Vue Query（或同等） | 列表/任务/模型 |
| 客户端状态 | Pinia | 用户/权限/偏好 |
| 路由状态 | URL query | 分页/筛选/Tab |
| 静态服务 | **Nginx（F3）** / FastAPI StaticFiles（F2） | 禁止长期 `vite preview` 当生产 |

离线构建用预置 npm cache / 内网镜像；现场不远程 `npm install`。开发机可用 npmmirror。

## 3. 页面设计（按旅程 · 6 顶级 + 子路由）

侧栏按 **看数 / 接入 / 治理 /（系统）** 分组；`ops` 角色可见「系统」。旧路由保留 **redirect**（见 [13-页面功能收敛](question/13-页面功能收敛与信息架构.md) §五）。

| 旅程 | 路由 | 页面 | 说明 |
|---|---|---|---|
| 看数 | `/` | 数据概览 | 待办 + KPI + 数据规模摘要；链入数据中心 |
| | `/ask` | 问数 | 自然语言 ad-hoc 查数 |
| | `/data` | **数据中心** | Tab：明细浏览 / 汇总报表 / 趋势分析 |
| 接入 | `/intake` | 接入与任务 | 上传 + 任务历史；`/files` → redirect |
| | `/stage/:fileId` | Staging 确认门 | 不进侧栏 |
| 治理 | `/govern` | **治理中心** | Tab：待确认 / 规则资产 / 指标口径（只读） |
| 系统 | `/system` | **系统** | Tab：运维 / 模型 / 血缘 / 审计 / 指标维护 / 设置 |

**Redirect（兼容书签）**：`/browse`→`/data?tab=detail` · `/reports`→`tab=report` · `/learning`→`/govern?tab=assets` · `/metrics`→`/govern?tab=metrics` · `/ops|/models|/lineage|/audit|/settings`→`/system?tab=*`

### 3.1 数据概览（Dashboard，`/`）

- **待办条**：流水待确认、gate 未就绪时醒目提示，链入治理中心。
- **业务快照**：9 项 KPI（`metric_id` 可点进口径）；Top 类别/库位/单位；近 6 月出入库迷你趋势。
- **数据规模**：5 张表行数（物理 `COUNT(*)`，与 KPI 口径区分）；一键进入数据中心。
- **最近接入**：0–1 条摘要 → `/intake`。
- **不含**：模型 Stage 卡、底部全站导航、黑盒 CSV 导出、报表种子详表。
- 数据源：`GET /api/v1/stats/overview`、`GET /api/v1/analytics/flow-monthly`。

### 3.2 问数（Ask，`/ask`）

- 提问框 + 本会话历史。
- 结果区：答案卡片 + SQL（可折叠）+ 数据表格；超过 `QUERY_ROW_LIMIT` 时展示截断提示（`total_rows` / `truncated`）。
- 数据源：`POST /api/v1/ask`。

### 3.3 数据中心（Data，`/data`）

```
/data?tab=detail|report|trend
├─ 明细浏览   BrowseView — GET /browse/{table}?mode=business（默认），PagedTable 10/20/50/100
├─ 汇总报表   ReportsCatalog — 种子报表运行/下载（无 SQL 列；种子报表免 Ops Token）
└─ 趋势分析   FlowAnalytics — GET /analytics/flow-monthly|top|level
```

页顶说明：**明细核对用「明细」；汇总定稿用「报表」；趋势看图用「趋势」。**  
导出：`GET /export/table/{table}?mode=business` 或报表产物 `GET /reports/{run_id}/file`。

### 3.4 接入与任务（Intake，`/intake`）

- **上传区**：拖拽/多文件 → **202 + task_id**；上传进度（XHR）与解析进度（**SSE** `/events/…`）分两段展示（11 §8）。  
- **任务历史**：同页 Tab 展示 `GET /api/v1/tasks` 列表（status 筛选）；SSE 断线降级 toast + 轮询 `GET /api/v1/tasks/{id}`。  
- **接入报告**：六步步骤卡片；证据可展开（`/stage/:fileId`）。  
- **确认门**：staging 影响 + dry-run → confirm（鉴权 + version）；`409` 提示刷新；互验 conflict 禁止直接确认。  
- 数据源：`/api/v1/files*`、`/api/v1/tasks/*`、`/api/v1/intake/*`（03/05）。  

### 3.5 治理中心（Govern，`/govern`）

```
/govern?tab=work|assets|metrics
├─ 待确认     GovernView — 映射/流水/勾稽/主数据等 Tab
├─ 规则资产   AssetsView — rule_dict / flow_example / fewshot / 确认历史
└─ 指标口径   MetricsView（editable=false）— 只读浏览 + 试跑/趋势
```

- **流水解析**：`flow_pending` 分页（PagedTable）；接受/修正/忽略回写 `flow_example`。
- **勾稽差异**：按物资展示 ΣIN−ΣOUT 与库存差。
- 写操作需 Ops Token；数据源：`/api/v1/govern/*`、`/api/v1/master/*`。

### 3.6 系统（System，`/system`）

```
/system?tab=ops|models|lineage|audit|metrics|settings
├─ 运维面板   OpsView
├─ 模型管理   ModelsView
├─ 版本血缘   LineageView
├─ 审计时间线 AuditView
├─ 指标维护   MetricsView（editable=true）
└─ 设置       SettingsView — Ops Token / X-Ops-Role
```

仅 `ops` / `admin` 角色侧栏可见「系统」入口（`localStorage.ops_role`）。

### 3.7 模型管理（Models，`/system?tab=models`）

展示样式参考 Handy：**分组卡片** + 顶部工具条（搜索 / 重新扫描 / 筛选）。

**模型卡片字段**：模型名、角色徽标（embed/fast/big）、状态徽标、职责描述、端点/调用统计、操作（设为活跃 / 受控重启）。

**状态枚举**（卡片：active/deployed/importing/configured/unreachable/not_configured；调用 9 态见 01 §5.5）。

- 数据源：`GET/POST /api/v1/models…`（切换/重启/导入 **ops**；Phase A/B 无在线下载）。

### 3.8 指标字典（Metrics）

- **治理 Tab**（`/govern?tab=metrics`）：只读列表 + 试跑/趋势。
- **系统 Tab**（`/system?tab=metrics`）：编辑、`definition_sql` 试跑、冲突检查、流水指标激活门禁。
- 数据源：`GET/POST /api/v1/metrics`（写 **ops**）。

### 3.9 自学习资产（Assets，`/govern?tab=assets`）

规则字典 / 流水示例 / fewshot / 确认历史；统一 `PagedTable`（10/20/50/100）。

- 数据源：`GET /api/v1/assets/*`。

### 3.10 运维 / 血缘 / 审计 / 设置

挂入 `/system` 对应 Tab（Ops / Lineage / Audit / Settings）；401 引导至 `tab=settings`。

## 5. 端口、同源与错误展示

- **正式（F3）**：浏览器只访问 `127.0.0.1:8080`；不依赖 CORS。  
- **开发（F1）**：Vite 代理，浏览器不直连 `:8010`。  
- PoC 若暂时双端口，CORS 仅放行本机前端源；允许头含鉴权与 `Idempotency-Key`、`X-Request-ID`。  
- 错误：按 `code` 分支；默认简明文案 + 可展开 `request_id`；禁堆栈/库路径/prompt（11 §11）。  
- `409`：提示刷新影响评估后重试；`503`：标明模型/依赖不可用与可执行动作。
