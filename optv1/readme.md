# 用户视角产品评审总览

## 文档目的本文档组从真实使用者视角评审`smart-material-system`。重点不是系统是否“功能齐全”，而是用户能否理解、信任并完成物资数据规整与治理工作。
本文档组不替代docs/中既有架构与治理方案SSOT。若本文档组与docs/的正式决策冲突，以docs/为准；本文档组只描述用户体验、页面组织、产品表达和分阶段改造建议。

## 核心结论当前系统已经具备数据接入、质量检查、治理确认、数据浏览、问数和本地模型辅助能力。但页面表达仍偏向程序员、运维和系统内部模块，没有充分围绕业务用户的工作流组织。
更准确的产品定位应从：
> 本地大模型数据分析系统
调整为：
> 本地部署的智能物资数据规整与治理系统大模型不是主角。主角应该是原始物资数据如何被接入、清洗、规整、治理、确认、输出和追溯。模型只负责给出建议、解释和辅助判断。

## 当前主要问题

### 页面面向系统模块，而不是用户任务
当前导航包含“看数、接入、治理、系统”，并将问数、数据中心、治理中心、系统管理作为主要入口。这个结构已经比纯技术页面更好，但仍存在以下问题：
- 用户进入页面后，需要理解系统内部概念才能知道下一步。
- 数据规整能力没有被单独突出。
- 治理中心像功能集合，而不是待办工作区。
- 模型、血缘、审计、指标维护等高级能力容易打断业务主线。
- “可用数据、规整数据、阻塞数据、发布数据”的状态边界不够清晰。
- ###大模型能力容易喧宾夺主
本地模型是重要卖点，但用户真正关心的是数据能不能规整成可信结果。若页面过度强调模型状态、模型问答或模型调用细节，用户会误以为系统目标是“聊天分析数据”，而不是“治理和规整数据”。

### 数据规整主线不清晰
用户需要看到一条明确链路：
原始文件 -> 结构识别 -> 字段规整 -> 物资规整 -> 单位口径规整 -> 异常处理 -> 人工确认 -> 可用数据 -> 发布/导出 -> 追溯审计。
当前页面中已有部分能力，但缺少面向用户的统一表达。

## 目标用户

### 业务数据人员
主要任务：
- 上传物资相关Excel、CSV或JSON文件。
- 理解系统识别出的字段、物资、单位和异常。
- 确认或修正治理建议。
- 导出规整后的可用数据。
他们不应该被迫理解：
- API端点。
- 原始JSON。
- 模型endpoint。
- 技术任务id。
- DuckDB或SQLite表结构。
- 内部evidence/raw/staging命名。

### 数据治理人员
主要任务：
- 维护字段映射、物资主数据、单位口径、分类规则和治理规则。
- 审核低置信匹配和规则冲突。
- 判断规则变更对历史数据的影响。
他们可以看到更细的治理证据，但仍不应直接面对底层实现细节。

### 管理或审核人员
主要任务：
- 看当前数据是否可用。
- 看还有哪些阻塞问题。
- 看数据成果和差异。
- 看关键操作和发布记录。
他们需要的是摘要、趋势、待办和审计证据，而不是系统配置。

### 运维或管理员
主要任务：
- 查看模型、API、worker、任务、备份、磁盘和健康状态。
- 配置token、模型端点、部署边界和运行参数。
这类能力应进入“系统设置”或“运维”区域，不应出现在普通业务主路径中。

## 统一术语

### 原始数据用户上传或系统接入的源文件内容。原始数据只作为证据保存，不直接代表可用结果。

### 暂存数据系统解析后等待确认的数据。暂存数据可以用于画像、预检查、治理建议和影响预演，但不应被当成正式结果。

### 规整数据经过字段、物资、单位、分类、编码和异常处理后的统一结构数据。规整数据仍可能包含阻塞项。

### 可用数据通过当前质量门禁、可以被导出或继续分析的数据。可用数据不等于正式发布数据，也不等于库存事实。

### 阻塞数据因缺字段、低置信匹配、异常值、规则冲突或人工未确认等原因，暂时不能进入可用结果的数据。

### 发布数据经过审批、绑定源版本、规则版本、处理任务和发布清单的数据。正式报告应读取发布数据，而不是读取当前缓存或临时批次。

### AI建议本地模型基于输入证据给出的候选映射、分类、解释或问数辅助结果。AI建议必须经过规则校验或人工确认，不能自动成为业务事实。

## 产品原则

### 用户先看到结论，再看证据页面应先回答“能不能用、为什么不能用、下一步做什么”，再提供详细证据。

### 业务主路径默认简单，高级信息按需展开原始JSON、模型响应、任务事件、血缘细节和审计明细应作为高级详情，不应默认压到普通用户面前。

### 数据治理是主线，大模型是辅助问数和模型建议不能替代数据规整。模型只能参与建议、解释、候选生成和低置信场景辅助。

### 状态命名必须谨慎不能把“可用数据”命名为“最终数据”。不能把“下载当前结果”表达成“正式发布”。不能把“AI建议”表达成“已自动处理”。

### 所有关键结果必须可追溯用户看到的每个结果都应能追溯到源文件、Sheet、行、原始值、规则、模型建议、人工确认和处理任务。
