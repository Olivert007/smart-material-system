# 报表导出预览能力问题记录与修改计划

> 适用页面：/data?tab=report
> 记录目的：先记录"报表运行后无法预览内容"的业务问题，再进行代码修改。

## 1. 当前问题

数据成果→报表导出当前只支持：

1. 查看报表名称、分组、参数。
2. 点击"运行"。
3. 运行后显示行数、运行编号、来源版本、指标口径版本。
4. 点击"下载"后在本地打开文件。

页面没有展示报表内容预览。用户必须下载到本地后，才知道报表里有哪些列、哪些数据、是否符合预期。

## 2. 用户视角问题

业务用户运行报表时，通常需要先判断：

1. 报表是不是自己要的那一张。
2. 参数是否填对。
3. 筛选结果是否为空。
4. 字段列是否符合业务理解。
5. 数据内容是否明显异常。

如果只能下载后查看，会带来两个问题：

1. 操作链路变长：运行、下载、打开文件、确认、返回页面。
2. 容易误下载：用户不知道结果是否正确就下载完整报表。

## 3. 修改目标

运行报表后，页面应立即展示结果预览。

目标交互：

1. 点击"运行"。
2. 页面显示最近运行结果。
3. 在同一区域展示前 20 行数据预览。
4. 用户确认内容后，再点击"下载完整报表"。

## 4. 后端方案

新增接口：

```text
GET /api/v1/reports/{run_id}/preview?limit=20
```

返回：

```json
{
  "run_id": "run_xxx",
  "row_count": 100,
  "preview_count": 20,
  "columns": ["物资名称", "库存数量"],
  "rows": [
    {"物资名称": "光缆", "库存数量": 100}
  ]
}
```

实现要求：

1. 只能读取已生成的报表产物。
2. limit 默认 20，最大 100。
3. 支持当前报表产物格式。
4. 空值返回 null，避免前端出现 "NaN"。
5. 预览接口只读，不重新运行报表。

## 5. 前端方案

修改 `ReportsCatalog.vue`：

1. 运行成功后自动加载预览。
2. 最近运行结果下方增加"数据预览"表格。
3. 预览表格展示前 20 行。
4. 下载按钮改为"下载完整报表"。
5. 结果为空时提示：

```text
当前报表无数据，请调整参数后重新运行
```

## 6. 文案调整

当前：

```text
运行
下载
最近运行结果
```

建议：

```text
运行并预览
下载完整报表
最近运行结果
数据预览（前20行）
```

## 7. 验收标准

1. 打开 /data?tab=report。
2. 点击任意无参数报表的"运行并预览"。
3. 页面显示总行数。
4. 页面显示前 20 行预览表格。
5. 点击"下载完整报表"可以下载完整文件。
6. 不需要下载文件，也能知道报表大概内容。
7. 预览区不展示运行文件路径、内部 SQL、内部错误堆栈。
